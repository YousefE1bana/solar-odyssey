# Assets and Reproduction

`Textures/provenance.json` is the retained runtime texture inventory. Every entry includes its output SHA-256, attribution, source URL, transformation and limitations. `cmake/StageRuntimeTextures.cmake` is the packaging union of loaders and all selectable variants, not one preset's current subset.

## Imagery

Classic Milky Way and planetary illustrations are INOVE/Solar System Scope CC BY 4.0 adaptations. Scientific layers are JPL visualizations, not calibrated measurements. The Scientific Composite is a per-channel maximum of three catalog images, not a deduplicated star database. The redundant sparse `8k_stars.jpg` is retired.

Seven moons have global imagery: Moon, Enceladus, Europa, Ganymede, Tethys, Dione and Rhea. Eleven unresolved moons use deterministic spherical procedural craters/noise. They are labeled procedural, never reconstructed terrain. Partial or uncertain maps are not sphere-wrapped.

The new Tethys and Dione global simple-cylindrical grayscale masters are positive-west longitude products. Horizontal mirroring converts them to east-increasing texture U; Lanczos downsamples them to 4096x2048 without filling terrain. Rhea uses the official full 1024x512 rendition because the product page's TIFF link points to a different older map. Its modest resolution is retained honestly. Mission mosaics contain inherited lighting and processing, and no artificial detail is added.

## Reproduce

Install Pillow 12.2.0 for the original encoding environment. Download the authoritative source URLs listed in the manifest into `.output/qa/sources/`, using `Tethys.tif`, `Dione.tif` and `Rhea.jpg` for the new moons. `prepare_moons.py` checks the source digests before conversion.

```powershell
python tools/assets/prepare_moons.py
python tools/assets/verify_assets.py
```

Older scientific JPEGs are native-resolution transcodes (or specified Enceladus Lanczos resamples). Their source digests and exact transformation are retained in the manifest, so masters need not live in Git. Grayscale preserves mode L at quality 92; color uses quality 95 and 4:4:4. Scientific Composite uses the per-channel maximum of the three catalog JPEGs. Encoder-version differences can change output bytes; verify rather than silently accepting a changed asset.

INOVE assets are delivered adaptations; their output checksums identify the exact shipped files, while the provider URL and notices preserve source/legal provenance. No claim is made that an undocumented historical adaptation can be regenerated byte-for-byte.

## Audio and Branding

The unmodified Out in Space pair by Agecaf is CC0, explicitly dedicated by the author on [the source page](https://opengameart.org/content/out-in-space-0). `assets/audio/provenance.json` identifies the shipped bytes. Both Ogg voices start together; four menu loops match one exploration loop. A 1.4-second smooth gain crossfade preserves playback phase when entering gameplay or returning to the menu. Pause retains exploration music and does not restart playback. Exploration gain is 58% of menu gain; master/music preferences persist. UI/instrument cues remain brief synthesized tones. No unverified candidate recordings ship.

The orbital mark in `icon.ico` has 16, 24, 32, 48, 64, 128 and 256 pixel sizes. The executable's resource object depends explicitly on that file so incremental builds cannot retain stale artwork. `icon.png` supplies the GLFW window icon; `assets/branding/` contains original presentation masters. The removed yellow Sun application JPEG was obsolete branding; `Textures/sun.jpg` remains legitimate celestial imagery.
