This folder contains texture assets used by the Solar Odyssey.

Ensure the following files exist for best visuals:
- sun.jpg
- saturn_ring_alpha.png
- stars_milky_way.jpg
- earth_daymap.jpg
- earth_nightmap.jpg
- earth_clouds.jpg
- venus_surface.jpg
- venus_atmosphere.jpg
- moon.jpg

If a texture is missing, the program will attempt a fallback and mark it in Diagnostics UI.
