# Changelog

## 1.1.0

- New live Earth opening with richer Classic Milky Way as the fresh-install sky.
- Optional menu-to-exploration cinematic with movement cancellation, remote-save fade, and immediate direct-entry fallback.
- Five persistent starfield choices, independent of graphics quality, all included in packages.
- Global Cassini/Voyager imagery for Tethys, Dione and Rhea; procedural cratered materials for unresolved moons; proportional small-body framing.
- Discovery Codex and progression removed. Instrument feedback is passive and cannot capture flight control.
- Contextual free-flight HUD, scalable notifications, scrollable Settings, cleaner photography and navigation.
- Wrapped dossier metrics remain legible at supported UI scales; windowed frames fit inside the desktop work area.
- Fullscreen by default on fresh launch, with saved windowed preference respected.
- Replaced ambience with Agecaf's CC0 Out in Space pair, phase-synchronized menu/gameplay crossfades, audible menu defaults and quieter exploration. Pause does not restart music.
- Fixed executable and running-window icon resources, HUD-focused keyboard blocking and mouse-release capture.
- Save schema 6 migrates versions 1-5 without retaining retired progression.
- Curated source assets, public documentation and ignored build/release output; obsolete reports, captures, maps and recordings removed.
- Restored the supported Windows `build.bat` entry point for Release, Debug and native tests.

## 1.0.0

Initial Windows release: scientific exploration sandbox, 31-body roster, spacecraft, layered planetary rendering, photography and persistent simulation continuation. The original tagged source and release artifacts remain available.
